#UI/UX Fix List - June 2026
#Login Page---------------------------
-Remove Blue Inputs: Change the active/filled input background from blue 
back to a neutral light grey or white. Blue breaks the brand palette.

-Fix Form Width: Constrain the form container width so it doesn't look 
lost or stretched out on wide desktop screens.

-Toggle State: Make the password eye icon change color when clicked to 
show it is active.

#Dashboard & Student Table---------------------------
-Add Dropdown Arrows: Add a small down chevron/arrow to 
each filter button so users know they are clickable dropdowns.

-Fix Filter Spacing: Reduce the large gap between the "Filter" 
text label and the first dropdown button.

-Replace Edit/Delete Links: Change the text links (Edit | Delete) 
to distinct icon buttons (like a pencil and a trash can). The current 
text links are too small and risk accidental deletion clicks.

-Align "Add Student" Button: Fix the vertical alignment of the "Add Student" 
button so it lines up properly with the "Students" header, or move it up next 
to the main page title.

-Fix Text Crowding: Increase table column padding or row height. Long names 
are wrapping awkwardly due to the new Gender column.

#Style Guide Updates------------------------------------
-Increase Text Size: Change paragraph font sizes from 10px and 12px to a 
minimum of 14px. 10px is too small to read.

-Clean Up Colors: Merge "Neutral" and "Dark Text" into one single 
dark charcoal color for body text to avoid developer confusion.

Color change considertation to not match the PUP theme Red and Gold.
